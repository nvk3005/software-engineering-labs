# Bài Tập Buổi 01 - CRUD với Express.js – Sequelize - MySQL

---

## Nội dung chính

1. **Cấu hình dự án**:
   - Cài đặt các thư viện cần thiết.
   - Cấu hình kết nối cơ sở dữ liệu.

2. **Xây dựng mô hình dữ liệu**:
   - Tạo các model Sequelize.
   - Sử dụng migration để quản lý schema của cơ sở dữ liệu.

3. **Xây dựng API CRUD**:
   - Tạo các route và controller để thực hiện các thao tác CRUD (Create, Read, Update, Delete).

4. **Giao diện người dùng**:
   - Sử dụng view engine (EJS) để xây dựng giao diện cơ bản.
   - Hiển thị danh sách người dùng, thêm mới, chỉnh sửa và xóa người dùng.

---

## Cách chạy dự án

- Clone dự án từ url:
  ```bash
  git clone https://github.com/nvk3005/software-engineering-labs.git
  ```
- cd vào thư mục dự án:

  ```bash
  cd Buoi01_0504\TrenLop
  ```

- Chạy lệnh để cài đặt các thư viện cần thiết:
  ```bash
  npm install
  ```
- Sử dụng file `.env.example` để cấu hình môi trường.
- Chạy ứng dụng bằng lệnh:
  ```bash
  npm start
  ```
  Sau đó truy cập giao diện tại: [http://localhost:8088](http://localhost:8088)
